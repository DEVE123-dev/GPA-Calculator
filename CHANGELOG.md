# 📝 Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-05

### ✨ Added
- 🎯 Real-time GPA calculation with 5-point grading scale
- 📊 Beautiful dark theme UI with elegant design
- 💾 Auto-save functionality using localStorage
- 📄 PDF export with professional formatting
- 💾 Import/Export data as JSON for backup
- ⌨️ Keyboard shortcuts for power users:
  - `Ctrl/Cmd + Enter` - Add new subject
  - `Ctrl/Cmd + S` - Save data as JSON
  - `Ctrl/Cmd + E` - Export as PDF
  - `Ctrl/Cmd + R` - Reset all data
- 📱 Fully responsive design for mobile and tablet
- ♿ Accessibility features with ARIA labels
- 🎨 Animated GPA updates and smooth transitions
- 📈 Grade point calculation per subject
- 🔢 Support for decimal credit points
- ✅ Input validation with error messages
- 🎓 Visual grading scale reference
- 🗑️ Row removal with confirmation for last row
- 🔄 Reset functionality with confirmation dialog

### 🛠️ Technical
- Pure vanilla JavaScript (no frameworks)
- CSS custom properties for theming
- LocalStorage for data persistence
- jsPDF library for PDF generation
- Google Fonts (Playfair Display & DM Sans)
- Semantic HTML5 markup
- Modern ES6+ JavaScript

### 📚 Documentation
- Comprehensive README with features and usage
- MIT License
- Contributing guidelines
- GitHub issue templates
- Changelog

### 🎨 Design
- Dark theme with accent colors
- Smooth animations and transitions
- Hover effects on interactive elements
- Color-coded GPA bands (Fail/Pass/Credit/Distinction/HD)
- Professional typography
- Responsive table layout
